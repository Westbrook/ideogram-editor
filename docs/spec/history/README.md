# Historical input snapshots

Every other file in this directory is an exact, unmodified UTF-8 snapshot of a source note captured at Task 7 start on 2026-09-26. Filenames are original note IDs; `spec.md` is the workspace Spec. The synchronization manifest records title, named version, hash and purpose. These files intentionally retain earlier drafts, failed reviews, obsolete status and superseded policy wording. They are evidence only. Read [the current Technical Specification](../index.md) and its six owning sections for operative requirements.

Original task/review notes remain in the workspace with their complete histories. Historical snapshots are never silently rewritten for modern links or formatting; original workspace links and source-local paths remain evidence of their original context. Only current documents are subject to portable-link and current-status gates. Snapshot hashes protect the exact original bytes, including any historical formatting defects.
