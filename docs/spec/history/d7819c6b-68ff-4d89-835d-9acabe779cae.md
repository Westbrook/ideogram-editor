## 2. Consumers, layers and test ownership

**Priority: unit > integration > end-to-end (e2e).** This is a risk/feedback preference, not a test-count quota. A journey can need several layers when each checks a different failure boundary. Do not reproduce every unit permutation in a browser, require exactly one layer per journey, or use coverage percentage as completion.

| Code | Consumer and owning test layer | Real boundary and reason |
| --- | --- | --- |
| U | Developer consuming a public domain/adapter API; user outcomes expressed through it | Pure typed commands, validators, projections, serialization, reference graph, geometry and canonical arithmetic. Node test runner is the default proposed runner. Deterministic inputs; assert public results/errors and immutable inputs, not call order/private fields. |
| L | End user whose work must survive; developer consuming local HTTP/command contracts | Integration with the actual Node server/writer worker, SQLite/file storage, serializers, codecs and local provider emulator. Fresh temporary storage root and real durability/reopen. Required for atomicity, process boundaries, bytes, transport and races that a reducer cannot prove. |
| B | Browser user consuming controls, native input and rendered editor behavior | Browser integration with packed real en-reve components, app-owned native textarea, renderer and real local backend where authority matters. Playwright operates accessible roles/names/public values; native input, focus, shadow event propagation and presented pixels cannot be inferred from a DOM shim. |
| E | End user completing a small complete product workflow | Full built editor + backend + local emulator; minimal E1–E5 below. Catches integration/wiring across independently tested boundaries, never supplies the exhaustive fault/route matrix. |
| M | Keyboard/assistive-technology/native IME user | Explicit manual native protocols (§9), with device/version/event/observation receipts; synthetic events and axe cannot substitute. |
| P | User waiting for feedback and developer waiting for a build | The existing PERF-8 P/Q3/E campaigns (§11), real timing/storage/rendering on their named hardware. P here denotes performance methods; PERF expanded E is distinct from functional e2e E1–E5. |
| V | Developer integrating the real provider | Separately authorized, cost-bounded live contract observation (§12); local fixtures never count as Fal verification. |

Responsible roles: UI owns browser controls, focus and announcements; State owns commands, history, migrations and semantic projections; Raster owns canonical pixels/layout/geometry; Assets owns bytes/fonts/copies/GC; Jobs owns routing, transport, uncertainty and capacity; Training owns dataset preparation/lineage; Build owns manifests, consumer packaging, runners and retained evidence. Assign named maintainers before implementation release. Shared rows have one accountable role and explicit collaborators.

Use public imports from DS-1.1, not installed-package private scripts, forms-private, internal shadow selectors or source aliases. For actual public contract regressions, mount real controls and observe settled public properties/FormData plus the app receipt. A later en-change veto, equal authoritative write, accepted nested change or owner disposal must prevent obsolete app work. en-input is draft observation; en-action is not durable success; en-reorder is a cancelable proposal before mutation. Domain generation tokens are app-owned; never read the library's private revision counters. Register one action path so click/en-action cannot issue duplicate commands. Signals/render callbacks and rollback perform no irreversible work.

Expose a narrow app-owned test driver for supported commands, receipt/state queries, owned canonical output and fault barriers. Its observations are consumer contracts, not private state mutation. An emulator is allowed only at the provider/storage network boundary. Use test-only deterministic fault injection at documented writer/asset boundaries for crash timing; follow with real process termination/reopen. Do not mock SQLite, the filesystem, fonts, native selection or the renderer in the integration test claiming those behaviors.
