# Ideogram Editor — Technical Specification

Assembly **SPEC-A2**, 2026-09-26 UTC. Status: ready for independent final specification review; Task 7 is not self-approved. The six input sections have independent source-readiness approval. Implementation remains provisional at the owned qualification gates below. No editor implementation, application tests, benchmarks, package installation, provider calls or deployment are claimed.

Build a local, recoverable, Photoshop-like browser editor around the documented Ideogram V4 family on fal.ai and the en-reve design system. The initial product edits native image and text layers, authors separate semantic composition descriptions, and submits explicitly reviewed immutable requests through a localhost backend. It preserves originals, exact canonical pixels outside edit masks, durable history and unused candidates. This is a specification and implementation-planning handoff, not an authorization to start implementation.

## Accepted decisions

- **DEC-02:** U02 preview and explicitly approve resize, retaining originals.
- **DEC-03:** U03 queued finished results first; model preview streams deferred.
- **DEC-04:** U04 reconcile uncertain submissions, then explicit new attempt.
- **DEC-05:** U05 guided versioned dataset builder; training later.
- **DEC-06:** U06 generated results are raster; native text separately required.
- **DEC-07:** U07 clearly labeled cost estimates and unknown fees.
- **DEC-08:** U08 configurable concurrency initially one active request.
- **DEC-09:** U09 keep unused candidates until explicit dependency-safe deletion.
- **DEC-10:** Exact editor-owned outside-mask preservation.
- **DEC-11:** Support trained and imported V4 adapters independently of trainer completion.
- **DEC-12:** Vendor immutable coherent en-reve package archives in editor repo.
- **DEC-13:** Browser rendering first; SSR optional and measurement-driven.
- **DEC-14:** Align feedback/frame metrics with web.dev without replacing completion clocks.
- **DEC-15:** Persistent left request panel; reviewed desktop wireframe.
- **DEC-16:** Native editable text initially; composition follows V4 concepts without becoming native document authority.
- **DEC-17:** Initial document envelope: 25,000,000 pixels, 8192 per side, 100 combined image/text layers.
- **DEC-18:** Interleaved selected composites default to a new document.
- **DEC-19:** Portable copies default to full editing history and referenced closure.
- **DEC-20:** Local files first for V4 adapter imports; direct URLs deferred.
- **DEC-21:** Fast initial; seamless tiling later.
- **DEC-22:** Guided training admission 1–100 images, 800MiB originals, 201MiB package, 4KiB UTF-8/caption.
- **DEC-23:** One typography style per text box.
- **DEC-24:** Explicit Apply or Cancel for text drafts.
- **DEC-25:** Explicit linked fields between separate Layers and Composition lists.
- **DEC-26:** Preview and explicitly approve missing-font substitution.
