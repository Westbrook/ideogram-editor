  Expected versions can contain that document/version; no arbitrary state setter.

  pending work checks it before publishing, records a terminal rejection when
  storage permits, and releases only its own pins after ongoing reads stop.
  Exact same-command retries return the original receipt. Cancellation does
  not erase source uploads, partial work, global roots or shared objects.

VALIDATION AND RESOURCE CONTRACT

Normative order: owner/purpose/length/reservation; isolated upload hash/length;
ZIP directory/header/type/path/duplicate/range checks; streamed CRC/SHA; strict
canonical versioned manifest/JSONL, refs, acyclic shared index, transactions and
complete typed closure; sealed resource validation; source/closure/namespace-
bound review; atomic durable acceptance. No archive code executes.

ZIP uses STORE and BigInt sizes/offsets including real ZIP64 fields. Paths are
only manifest.json, records/<canonical decimal>.jsonl, objects/<lowercase SHA>.
Reject compression, encryption/descriptors/multivolume, directory/executable/
symlink/device/link metadata, traversal/absolute/drive/UNC/backslash/percent/
casefold or duplicate names, header disagreement, overlap, prefixes/trailing
payloads and unsupported extras. CRC uses Node's public incremental zlib API.

Disk-backed SQLite indexes/worklists and paged mapping keep closure/index size
out of unbounded JS maps. IO chunks <=1 MiB; shared workspace two-IO and64
preparation admission remains in force. Metadata <=64 KiB, event bodies <=16
KiB, descriptor records <=16 KiB; events retain the frozen PF wrapper overhead.
Each manifest/JSONL working segment <=128 MiB, with further index segments as
needed. 128 MiB is NOT a total index cap; 4 GiB is NOT an archive/project cap.

Snapshot capture, temporary metadata/indexes, archive construction/extraction,
original-source retention and sealed raster workers use shared disk reservation
with25% overhead, existing1 GiB free margin and64 MiB emergency reserve. Resident
archive IO is bounded independently from image worker reservations; existing
512 MiB process envelope stops preparation honestly without quality downgrade.
No large parse is silently truncated. Native worker reservations/checks remain
inside the full operation. A failed import may leave unregistered content files;
it never deletes a shared object or publishes a partial namespace.
