Ideogram Editor public preview — distribution notices

This preview reuses the Spectrum 2 inspired En Reve theme and the editor's browser text renderer. It is an independent, limited preview of the local editor. Spectrum inspiration does not imply Adobe affiliation. Adobe Clean is not distributed; the theme uses an installed local font or a system fallback.

The accompanying files reproduce the source notices for En Reve, Lit, Signals, bundled Noto fonts and the complete sealed CanvasKit/native text distribution. Some native component notices describe portions of the supplied distribution rather than features exposed in this preview. Preserve these notices when redistributing the preview.

Source: https://github.com/Westbrook/ideogram-editor
Each filename in this directory corresponds to an exact notice selected in tooling/pages/notices.json in the source repository. The public artifact manifest records its published bytes.
