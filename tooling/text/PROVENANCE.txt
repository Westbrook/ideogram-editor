Fonts: four unmodified static official Noto regular upright normal-width faces.

Exact raw URLs, bytes, hashes and OFL1.1 records are in vendor/text/manifest.json.
Font name/copyright/version/license records extracted from actual bytes are in
vendor/text/font-records.json. All four actual OS/2 fsType fields are0.
Fonts are not subset, renamed or sold separately. Full font bytes and notices
must accompany project/export distributions. Bundled coverage is deliberately
finite: Latin combining/ligatures, Arabic bidi, selected CJK and monochrome
supplementary symbols. For example U+1D11E is NOT covered and preparation refuses
it with the exact codepoint. No universal language/emoji coverage claim.

Parser policy: bounded sfnt container/table/checksum/OS2/outline preflight before
isolated CanvasKit FreeType interpretation. Static TTF/glyf+loca and CFF1 OTF,
face0, regular400/width5/upright only. Collections, variable/color/bitmap/SVG,
unknown/restricted embedding and unsupported styles refuse. This is not a full
OpenType sanitizer or an OS process sandbox. OS/2 embedding rules are based on
https://learn.microsoft.com/en-us/typography/opentype/spec/os2#fstype;
container rules: https://learn.microsoft.com/en-us/typography/opentype/spec/otff.
Local license permission is an explicit caller review record, not legal advice
inferred from fsType. Later writer validation must retain this record.

Notices: unmodified font OFL records and original official package/supplemental
notices are retained. New custom-* notices come from the exact acquired source
trees (Skia, FreeType FTL, HarfBuzz, ICU, libpng, Wuffs, zlib and Emscripten).
Source/license mappings are sealed in source-closure.json. Portions of this

reserved. Supplemental historical notices do not replace exact-source notices.

TypeScript compatibility: a byte-checked copy of official0.40 declarations removes
only the obsolete @webgpu/types reference already supplied by TypeScript7 lib.dom.
Custom bounded/cache APIs are explicitly typed locally. No skipLibCheck.

Memory admission and lifetime policy: MEMORY.txt. A hard32MiB native maximum plus
bounded external allocations permits representative Latin/Arabic/CJK work inside
the shared reservation ceilings. This is logical preallocation accounting, not
measured RSS, a full envelope promise or P3 timing/platform/resource qualification.
